# Random Quote Generator

A simple Random Quote Generator application built with **HTML, CSS, and JavaScript**.

The application displays a random quote when the user clicks the **New Quote** button. The author's name is displayed below the quote. Each time the button is clicked, a new random quote and its corresponding author are shown.

Users can also exit the quote generator and return to the initial dashboard.

## Features

* Display a random quote
* Display the author of each quote
* Generate a new quote by clicking the **New Quote** button
* Update the author's name when a new quote is displayed
* Exit the quote generator
* Return to the initial dashboard

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Use

1. Open the application.
2. Navigate from the initial dashboard to the Random Quote Generator.
3. Click the **New Quote** button to display a random quote.
4. The author's name will appear below the quote.
5. Click **New Quote** again to generate another quote and author.
6. Click the **Exit** button whenever you want to return to the initial dashboard.
